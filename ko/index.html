Windows용 피드 리더

梢알고리즘 없이, 서두르지 않고 읽는 피드.

Kozue는 구독하는 웹사이트, 블로그, 팟캐스트, 채널을 한곳에 모아 줍니다. 계정이나 서버 없이 PC에서만 쓰거나, 이미 쓰고 있는 피드 서비스와 함께 쓸 수 있습니다.

Microsoft Store 무료 설치 프로그램 다운로드

서버 없이, 또는 내 서버로

Kozue를 처음 열 때 고릅니다. 계정을 여러 개 두고 바꿔 가며 쓸 수 있습니다.

이 PC에서

웹사이트 주소를 붙여 넣으면 Kozue가 피드를 찾아 내려받고 PC에 저장합니다. 가입이 필요 없습니다.

<link rel="alternate" type="application/rss+xml" href="/feed.xml">

내 서비스로

휴대폰이나 다른 컴퓨터와 같은 내용을 읽으세요. Kozue는 이미 쓰고 있는 피드 서비스와 동기화됩니다.

  • Miniflux
  • FreshRSS
  • Inoreader
  • Feedbin
  • Nextcloud News
  • NewsBlur
  • Tiny Tiny RSS
  • The Old Reader
  • Google Reader API
  • Fever API

천천히 읽기 위해

전문 보기

원래 사이트에서 글 전체를 가져옵니다. 메뉴, 사이드바, 광고 없이.

오프라인

최신 글과 즐겨찾기는 PC에 남습니다. 기차 안에서도, 인터넷이 끊겨도 계속 읽을 수 있습니다.

타임라인

Kozue가 책갈피처럼 보기마다 어디까지 읽었는지 기억합니다.

팟캐스트와 동영상

재생 위치를 기억하는 플레이어와, 읽으면서 계속 볼 수 있는 떠 있는 창. 라디오와 YouTube·Twitch 생방송도 지원합니다.

키보드로

j k로 이동하고, 스페이스로 넘기고, m으로 읽음 표시를 합니다. 내레이터와 NVDA를 고려해 만들었습니다.

내 언어로

스페인어, 영어, 독일어, 프랑스어, 이탈리아어, 포르투갈어, 아랍어, 중국어, 일본어, 한국어, 러시아어, 힌디어.

밝게, 어둡게, 내 취향대로

글꼴, 크기, 열 너비, 테마를 고르세요. Windows 테마를 따르게 할 수도 있습니다.

폴더, 즐겨찾기, 태그, 나중에 읽을 링크로 정리하고, 피드 종류나 단어로 필터를 만드세요.

Kozue에는 서버가 없습니다

  • 사용 데이터를 수집하지 않고, 광고나 분석 도구도 없으며, 개발자에게 아무것도 보내지 않습니다.
  • 비밀번호는 Windows 데이터 보호로 암호화해 저장합니다.
  • 내가 고른 곳에만 연결합니다: 내 피드, 글이 있는 웹사이트, 내 서비스.
  • 전체 개인정보 처리방침 (영어)

다운로드

무료입니다. 설치 방법을 고르세요.

Microsoft Store

Microsoft 서명이 있고 자동으로 업데이트됩니다. 가장 편한 방법입니다.

Store에서 열기

winget 곧 출시

터미널에서 설치하는 분을 위해. winget upgrade로 업데이트합니다.

winget install Kozue.Kozue

GitHub

설치 프로그램과 포터블 버전, 버전별 구성 요소 목록. 아직 서명하지 않아 처음에는 Windows가 경고할 수 있습니다.
