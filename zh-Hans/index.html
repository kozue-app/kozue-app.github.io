Windows 订阅阅读器

梢你的订阅，没有算法，不慌不忙。

Kozue 把你关注的网站、博客、播客和频道集中在一个地方。可以只在你的电脑上运行，无需账号或服务器，也可以配合你已经在用的订阅服务。

Microsoft Store 免费 下载安装程序

无需服务器，或用你自己的

第一次打开 Kozue 时选择。你可以有多个账号，并随时切换。

在这台电脑上

粘贴网站的地址，Kozue 会找到它的订阅源、下载并保存在你的电脑上。无需注册。

<link rel="alternate" type="application/rss+xml" href="/feed.xml">

配合你的服务

和手机或其他电脑上读到的一样：Kozue 会与你已经在用的订阅服务同步。

  • Miniflux
  • FreshRSS
  • Inoreader
  • Feedbin
  • Nextcloud News
  • NewsBlur
  • Tiny Tiny RSS
  • The Old Reader
  • Google Reader API
  • Fever API

为从容阅读而生

全文

从原网站取回整篇文章，没有菜单、侧边栏或广告。

离线阅读

最新的文章和你的收藏会保存在电脑上。在火车上或断网时，照样能读。

时间线

Kozue 会像书签一样，记住你在每个视图中读到哪里。

播客与视频

能记住播放位置的播放器，还有悬浮窗口，让你边读边看。也支持电台以及 YouTube 和 Twitch 直播。

键盘操作

j k 移动，空格键 向下滚动，m 标为已读。也为讲述人和 NVDA 设计。

用你的语言

西班牙语、英语、德语、法语、意大利语、葡萄牙语、阿拉伯语、中文、日语、韩语、俄语和印地语。

浅色、深色，随你调整

选择字体、大小、栏宽和主题。Kozue 也可以跟随 Windows 的主题。

用文件夹、收藏、标签和稍后阅读的链接来整理，并按订阅源类型或关键词创建筛选器。

Kozue 没有服务器

  • 不收集使用数据，没有广告或分析工具，也不会向开发者发送任何数据。
  • 你的密码会用 Windows 数据保护加密保存。
  • 只连接你选择的地方：你的订阅源、文章所在的网站和你的服务。
  • 完整隐私政策（英文）
