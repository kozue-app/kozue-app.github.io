Windows 版訂閱閱讀器

梢你的訂閱，沒有演算法，不必匆忙。

Kozue 把你追蹤的網站、部落格、Podcast 和頻道集中在一個地方。可以只在你的電腦上運作，不需要帳號或伺服器，也可以搭配你已經在用的訂閱服務。

Microsoft Store 免費 下載安裝程式

不需要伺服器，或用你自己的

第一次開啟 Kozue 時選擇。你可以有多個帳號，並隨時切換。

在這台電腦上

貼上網站的網址，Kozue 會找到它的訂閱來源、下載並存在你的電腦上。不用註冊任何東西。

<link rel="alternate" type="application/rss+xml" href="/feed.xml">

搭配你的服務

和手機或其他電腦上讀到的一樣：Kozue 會與你已經在用的訂閱服務同步。

  • Miniflux
  • FreshRSS
  • Inoreader
  • Feedbin
  • Nextcloud News
  • NewsBlur
  • Tiny Tiny RSS
  • The Old Reader
  • Google Reader API
  • Fever API

為從容閱讀而做

全文

從原網站取回整篇文章，沒有選單、側邊欄或廣告。

離線閱讀

最新的文章和你的最愛會留在電腦上。在火車上或網路斷線時，照樣能讀。

時間軸

Kozue 會像書籤一樣，記住你在每個檢視中讀到哪裡。

Podcast 與影片

能記住播放位置的播放器，還有浮動視窗，讓你邊讀邊看。也支援廣播以及 YouTube 和 Twitch 直播。

鍵盤操作

j k 移動，空白鍵 往下捲動，m 標為已讀。也為朗讀程式和 NVDA 設計。

用你的語言

西班牙文、英文、德文、法文、義大利文、葡萄牙文、阿拉伯文、中文、日文、韓文、俄文和印地文。

淺色、深色，隨你調整

選擇字型、大小、欄寬和主題。Kozue 也可以跟隨 Windows 的主題。

用資料夾、最愛、標籤和稍後閱讀的連結來整理，並依來源類型或關鍵字建立篩選器。

Kozue 沒有伺服器

  • 不收集使用資料，沒有廣告或分析工具，也不會傳送任何資料給開發者。
  • 你的密碼會以 Windows 資料保護加密儲存。
  • 只連線到你選擇的地方：你的訂閱來源、文章所在的網站和你的服務。
  • 完整隱私權政策（英文）

下載

免費。選擇你想要的安裝方式。

Microsoft Store

由 Microsoft 簽署，並自動更新。最方便的方式。

在 Store 中開啟

winget 即將推出

適合從終端機安裝的人。用 winget upgrade 更新。

winget install Kozue.Kozue

GitHub

安裝程式和免安裝版，附上每個版本的元件清單。尚未簽署：Windows 第一次可能會跳出警告。

查看各版本
