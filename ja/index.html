Windows 用フィードリーダー

梢アルゴリズムなしで、ゆっくり読むフィード。

Kozue は、フォローしているサイトやブログ、ポッドキャスト、チャンネルをひとつにまとめます。アカウントもサーバーもいらず PC だけで動き、すでに使っているフィードサービスとも連携できます。

インストーラーをダウンロード 無料

サーバーなしでも、自分のサーバーでも

初めて Kozue を開くときに選びます。複数のアカウントを持ち、切り替えられます。

この PC で

サイトのアドレスを貼り付けると、Kozue がフィードを見つけてダウンロードし、PC に保存します。登録は不要です。

<link rel="alternate" type="application/rss+xml" href="/feed.xml">

お使いのサービスで

スマートフォンや他のパソコンと同じ内容を読めます。Kozue はすでに使っているフィードサービスと同期します。

  • Miniflux
  • FreshRSS
  • Inoreader
  • Feedbin
  • Nextcloud News
  • NewsBlur
  • Tiny Tiny RSS
  • The Old Reader
  • Google Reader API
  • Fever API

ゆっくり読むために

全文表示

元のサイトから記事全体を取得します。メニューやサイドバー、広告はありません。

オフライン

最新の記事とお気に入りは PC に残ります。電車の中でも、ネットがつながらなくても読めます。

タイムライン

しおりのように、それぞれの表示でどこまで読んだかを Kozue が覚えています。

ポッドキャストと動画

再生位置を覚えるプレーヤーと、読みながら見続けられるフローティングウィンドウ。ラジオや YouTube・Twitch のライブ配信にも対応します。

キーボードで

j k で移動、スペース で先へ進み、m で既読にします。ナレーターや NVDA でも使えるように作っています。

あなたの言語で

スペイン語、英語、ドイツ語、フランス語、イタリア語、ポルトガル語、アラビア語、中国語、日本語、韓国語、ロシア語、ヒンディー語。

ライト、ダーク、好みに合わせて

フォント、サイズ、列の幅、テーマを選べます。Windows のテーマに合わせることもできます。

フォルダー、お気に入り、タグ、あとで読むリンクで整理し、フィードの種類や言葉でフィルターを作れます。

Kozue にはサーバーがありません

  • 利用データを集めず、広告も解析ツールもなく、開発者に何も送りません。
  • パスワードは Windows のデータ保護で暗号化して保存します。
  • 接続するのは、あなたが選んだものだけです。フィード、記事のサイト、そしてお使いのサービス。
  • プライバシーポリシー全文（英語）

ダウンロード

無料です。インストール方法を選んでください。

Microsoft Store 近日公開

Microsoft の署名付きで、自動で更新されます。いちばん手軽な方法です。

winget 近日公開

ターミナルからインストールする方へ。winget upgrade で更新できます。

winget install Kozue.Kozue

GitHub

インストーラーとポータブル版、各バージョンのコンポーネント一覧。まだ署名していないため、初回は Windows が警告を出すことがあります。
