Lector de feeds para Windows

梢Tus feeds, sin algoritmo y sin prisa.

Kozue reúne las webs, blogs, podcasts y canales que sigues en un solo sitio. Funciona solo en tu PC, sin cuentas ni servidores, o con el servicio de feeds que ya usas.

Microsoft Store gratis Descargar el instalador

Sin servidor, o con el tuyo

Elige al abrir Kozue por primera vez. Puedes tener varias cuentas y pasar de una a otra.

En este PC

Pega la dirección de una web y Kozue encuentra su feed, lo descarga y lo guarda en tu PC. Sin registrarte en nada.

<link rel="alternate" type="application/rss+xml" href="/feed.xml">

Con tu servicio

Lee lo mismo que en el móvil o en otros equipos: Kozue se sincroniza con el servicio de feeds que ya usas.

  • Miniflux
  • FreshRSS
  • Inoreader
  • Feedbin
  • Nextcloud News
  • NewsBlur
  • Tiny Tiny RSS
  • The Old Reader
  • API de Google Reader
  • API de Fever

Hecho para leer con calma

Texto completo

Trae el artículo entero desde su web, sin menús, barras laterales ni anuncios.

Sin conexión

Lo último y tus favoritos se quedan en el PC. En el tren o con la red caída, sigues leyendo.

Línea de tiempo

Kozue recuerda por dónde ibas en cada vista, como un marcapáginas.

Podcasts y vídeo

Un reproductor que guarda la posición y una ventana flotante para seguir viendo mientras lees. También radio y directos de YouTube y Twitch.

Con el teclado

j k para moverte, espacio para avanzar, m para marcar como leído. Y pensado para Narrador y NVDA.

En tu idioma

Español, inglés, alemán, francés, italiano, portugués, árabe, chino, japonés, coreano, ruso e hindi.

Claro, oscuro y a tu medida

Elige tipografía, tamaño, ancho de columna y tema. Kozue sigue al de Windows si quieres.

Organiza con carpetas, favoritos, etiquetas y enlaces para leer más tarde, y crea filtros por tipo de fuente o por palabras.

Kozue no tiene servidores

  • No recoge datos de uso, no tiene publicidad ni analítica y no envía nada a quien lo desarrolla.
  • Tus contraseñas se guardan cifradas con la protección de datos de Windows.
  • Solo se conecta a lo que tú eliges: tus feeds, las webs de tus artículos y tu servicio.
  • Política de privacidad completa

Descargar

Gratis. Elige cómo prefieres instalarlo.

Microsoft Store

Firmado por Microsoft y con actualizaciones automáticas. Lo más cómodo.

Abrir en la Store

winget pronto

Para quien instala desde la terminal. Se actualiza con winget upgrade.

winget install Kozue.Kozue

GitHub

El instalador y la versión portátil, con la lista de componentes de cada versión. Aún sin firmar: Windows puede avisar la primera vez.

Ver las versiones

Windows 10 (1809) o posterior, 64 bits.
